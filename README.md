# Expense Tracker

Simple three-tier expense tracker built with React, Node.js/Express, and MongoDB.

## Structure
- `frontend` — React + Vite dashboard
- `backend` — Express REST API
- MongoDB — expense persistence

## Run backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

## Run frontend
```bash
cd frontend
npm install
npm run dev
```

Backend: `http://localhost:4100`
Frontend: `http://localhost:5173`
